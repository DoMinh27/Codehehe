# Problem Bank Attribution

CodeHehe contains original exercises and Vietnamese stdin/stdout adaptations of
selected exercises from the Exercism Problem Specifications repository. The
adapted statements, constraints, test cases, starter code, and Python reference
solutions in CodeHehe were rewritten for the five-minute 1v1 format; CodeHehe
does not copy user submissions or solution implementations from Exercism.
